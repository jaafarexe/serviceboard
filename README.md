# ServiceBoard

A small service-business request organizer: add requests with customer, service type, date, time window and notes, then move them through a status pipeline (New → Scheduled → In Progress → Done). Includes filters, search, a Today view, and open/done counts. Data is stored locally in the browser.

## Run locally

Prerequisites: Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Build

`npm run build`
